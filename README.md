# school-pc-info

학교 선생님들이 각자 쓰는 노트북의 **제조년월(추정), CPU, RAM, 유선 IP**를 한 번에 모아 엑셀로 정리하는 도구입니다.

## 구성

| 파일 | 대상 | 설명 |
|------|------|------|
| `PC정보수집.bat` | 선생님들 | 더블클릭 → 성함 입력 → 바탕화면에 `성함.txt` 생성 |
| `PC정보취합기.html` | 담당자 | 받은 txt들을 끌어다 놓으면 엑셀(전체 / IP별 / 장소별 / 사용연한별 시트)로 저장 |
| `PC정보수집.zip` | 배포용 | `PC정보수집.bat` + `사용법.txt` (메신저가 .bat를 막을 때 사용) |

## 사용 순서

1. `PC정보수집.zip`을 선생님들께 배포합니다.
2. 선생님들은 압축을 풀고 `PC정보수집.bat`을 실행한 뒤, 바탕화면에 생긴 `성함.txt`를 보냅니다.
3. 담당자는 `PC정보취합기.html`을 브라우저로 열고 받은 txt들을 올립니다.
4. 필요하면 `성함, 장소` 명단을 붙여넣고, 사용연한 구간(기본 `3,5`)을 정한 뒤 **엑셀 파일로 저장**을 누릅니다.

## 참고

- 설치할 프로그램이 없습니다. 수집은 윈도우 기본 PowerShell, 취합은 브라우저만 사용하며 외부로 전송하지 않습니다.
- **제조년월**은 윈도우에서 정확한 값을 읽을 수 없어 BIOS 날짜로 추정합니다.
- **유선 IP**는 연결된 이더넷 어댑터만 대상으로 하며, 무선(와이파이)만 쓰면 "유선 연결 없음"으로 기록됩니다.
- 수집 항목: 성함, 컴퓨터이름, 제조년월(추정), CPU, RAM(GB), 유선IP, 수집일시
